**A score pad for the card and board games you already play.**

Set up a game in a few taps — individuals or teams, high score wins or low
score wins, with or without a target — and start scoring. Everyone reads the
same pad, round by round.

Card games don't agree on anything, so Meld doesn't assume. Add the columns
your game actually needs: plain scores, bids with a suit, running tallies for
bags or tricks, or a text note. Change the rules mid-game without starting
over, correct a cell you typed wrong, substitute a player, and archive the
game when it's done.

Meld has no sign-in, no subscription, no advertising, and no analytics. It
contains no networking code at all — everything you enter stays on your device.
